# Repository instructions

IMPORTANT: Do not remove, disable, replace, or add application functionality without explicit approval. Preserve existing features, workflows, data structures, behavior, app name, icon, and identity unless a change is specifically requested.

## Mandatory PD Nexus branding policy

Follow [PD-NEXUS-BRANDING-POLICY.md](./PD-NEXUS-BRANDING-POLICY.md) for every current and future application change in this repository.

In particular:

- Never add a PD Nexus logo, symbol, graphic, registered trademark symbol, or new logo asset.
- Never modify the existing CueFlow icon or replace CueFlow branding.
- Use exactly `Envisioned by PD Nexus`.
- Use exactly `IDEAS • APPS • IMPACT`.
- Use exactly `Support: pdnexus.apps@gmail.com` for visible support contact details.
- Keep creator credit small on splash/loading screens without extending startup time.
- Keep creator credit, tagline, application version, support email, and functional Feedback & Support in Settings.
- Use text-only PD Nexus branding in email signatures.
- Do not alter unrelated features or backend behavior.
